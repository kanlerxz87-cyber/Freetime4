# Freetime4

## Freetime planner (GitHub Pages)

Site source is in `docs/` (published from the `main` branch, `/docs` folder). Data is in `docs/data/`, with official raw API responses in `docs/data/raw/`. Scripts: `scripts/build_scoreboard.js` (scoreboard data), `scripts/build_site.js` (HTML pages), `scripts/check_ids.js` and `scripts/check_site.js` (checks). Coordination: see `COORDINATION.md`.
