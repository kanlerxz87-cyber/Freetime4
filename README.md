# Free Time Vacation Planner

A source-first Bay Area live-sports calendar for vacation planning. The site distinguishes confirmed schedule facts from unpublished schedules; it does not invent dates, kickoff/first-pitch times, radio carriage, or free-time windows.

## Run locally

Open `index.html` in a browser, or serve the repository root with any static HTTP server.

## Verification boundary

As of 2026-11-25, broad league schedule coverage and radio station carriage must be checked at the official source pages listed on the site. A published matchup date does not prove it will air on a Bay Area AM/FM station. A date with missing schedule data is **unknown**, not free. Game duration estimates are not used to mark confirmed free time; actual game end times vary.
