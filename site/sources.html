Sources used

Official sources are used for everything presented as fact. Where the official body publishes no machine-readable feed (NFL league schedule, NCAAF), values were read from a trusted official-mirroring feed and the official page is linked per row for manual review — flagged in the methodology.

Trusted aggregators (used for cross-checks; labeled, not passed off as official)
