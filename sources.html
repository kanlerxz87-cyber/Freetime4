Sources & methodology

How every value was obtained and how free time is computed

Verification standard

Every table row on this site carries a source link to an official league/team/broadcaster page. A row is marked ✓ verified only if its value was read on an official source during this session. Anything else is labeled est / unverified and listed on Flagged for Review. We never silently fill values: where a time is unknown it shows TBD or “time est”.

Bulk data was pulled from MLB's official Stats API (the data behind mlb.com/schedule) via a GitHub Actions fetch job committed to this repo under data/raw/ — the raw evidence is preserved, game-by-game. NFL/college cross-check dumps come from ESPN's public site API and are labeled as cross-checks.

Primary sources

  • MLB 2027 schedule release: mlb.com/news/mlb-2027-schedule-released (Opening Night Mar 24, Opening Day Mar 25, All-Star Jul 13, season end Sep 26)
  • MLB game-by-game: mlb.com/schedule / statsapi.mlb.com (per-month raw dumps in data/raw/)
  • NFL schedules: nfl.com/schedules (by-week pages used as per-row source)
  • Super Bowl LXI: lasuperbowlhc.com (Feb 14, 2027, SoFi Stadium)
  • Westwood One national NFL: westwoodonesports.com/nfl-schedule + station finder
  • 49ers: 49ers.com/schedule/2026 (times + radio)
  • Stanford: gostanford.com · Cal: calbears.com
  • Radio: KNBR, KTCT, A's Sacramento radio, Warriors radio

The full source log with per-item verification status is in research/sources.md.

Game durations used (free-time math)

LeagueDuration usedBasisSource

Your brief estimated MLB ≈ 150 min and football ≈ 180 min; the researched averages are slightly longer (2:38 / 3:12) and are used here. Free blocks are complements of merged game windows within each PST day.

How the vacation windows are computed

  1. Build the event set per scenario (core / no spring training / SF-radio-only).
  2. Mark every calendar day that contains ≥1 blocking event. Events labeled “possible” (Stanford bowl) never block; estimated slate rows always block (conservative).
  3. Find maximal runs of consecutive days with zero blocking events within each year.
  4. Score runs against 7 / 14 / 21-day targets.

In-season day-level free blocks (e.g. an April evening with no game) come from the same data on the calendar page, computed per-day in PST from scheduled start + average duration.

Time zone

All times are Pacific (PST/PDT), converted from the leagues' ET/UTC feeds with US DST rules (PDT = UTC−7 second Sunday in March → first Sunday in November; PST = UTC−8).

Nothing on this site is marked verified without a source read in this session. Irregularities live on the Flagged for Review page and in VERIFY.md.
