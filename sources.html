Raw evidence kept in the repo

This sandbox can only reach GitHub, so every official page is fetched inside a GitHub Actions job (.github/workflows/collect.yml) and the raw response is committed:

  • data/raw/mlb_2026_all.json, data/raw/mlb_2027_all.json — MLB Stats API responses
  • data/raw/nfl2026/nfl_*_week*.html — nfl.com weekly pages (15 files)
  • data/raw/nfl2026/49ers_official_2026.html — 49ers.com schedule page
  • data/raw/ncaaf/stanford_2026.html, cal_2026.html
  • data/raw/wwo_events/*.json — 439 Westwood One event pages with schema.org timestamps
  • data/collect-report.md, data/p*-report.md — HTTP status + byte count for every fetch
